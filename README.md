# Phasmophobia Basketball AFK Farm 🏀

Простой кликер на Python для автоматического фарма голов в лобби Phasmaphobia. Работает на оптимально быстрых настройках (симулирует нажатия реальной клавиатуры), поэтому игра его не блокирует.

## 🛠 Инструкция по установке

### Шаг 1. Скачать Python
У вас должен быть установлен Python желательно версия 3.13 
1. Скачайте Python с официального сайта.
2. **ВАЖНО:** При установке обязательно поставьте галочку **"Add python.exe to PATH"** в самом первом окне установщика.

### Шаг 2. Установить библиотеки (Один раз)
Откройте терминал (командную строку) в папке со скриптом и введите команду bash:

```
pip install keyboard pydirectinput
```

*Нажмите Enter и дождитесь окончания установки.*

### Шаг 3. Запуск и управление
1. Запустите скрипт через редактор кода или командой в терминале bash:
  
```
python main.py
```
  
2. Откройте Phasmophobia, подойдите к сетке и наведите прицел строго на мяч.
3. Управление:
   * **F8** — Запустить / Остановить автофарм.
   * **ESC** — Полностью закрыть программу.

> ⚠️ ** НА ВСЯКИЙ СЛУЧАЙ. Если кнопки не нажимаются в игре:** Закройте скрипт, запустите вашу среду разработки (VS Code / Terminal) **от имени администратора** и запустите код заново. Играм часто нужны админ-права для перехвата клавиш.
