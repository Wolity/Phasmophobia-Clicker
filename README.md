# Phasmophobia Basketball AFK Farm 🏀

## Russian Language

Простой кликер на Python для автоматического фарма голов в лобби Phasmaphobia. Работает на оптимально быстрых настройках (симулирует нажатия реальной клавиатуры), поэтому игра его не блокирует.

## 🛠 Инструкция по установке

### Шаг 1. Скачать Python
У вас должен быть установлен Python желательно версия 3.13 
1. Скачайте Python с официального сайта.
2. **ВАЖНО:** При установке обязательно поставьте галочку **"Add python.exe to PATH"** в самом первом окне установщика.

### Шаг 2. Установить библиотеки (Один раз)
Откройте терминал (командную строку) в папке со скриптом и введите команду bash:

```
pip install keyboard pydirectinput
```

*Нажмите Enter и дождитесь окончания установки.*

### Шаг 3. Запуск и управление
1. Запустите скрипт через редактор кода или командой в терминале bash:
  
```
python main.py
```
  
2. Откройте Phasmophobia, подойдите к сетке и наведите прицел строго на мяч.
3. Управление:
   * **F8** — Запустить / Остановить автофарм.
   * **ESC** — Полностью закрыть программу.

### ⚠️ НА ВСЯКИЙ СЛУЧАЙ
> **Если кнопки не нажимаются в игре:** закройте скрипт, запустите вашу среду разработки (VS Code / Terminal) **от имени администратора** и запустите код заново. Играм часто нужны админ-права для перехвата клавиш.




# English Language

A simple Python clicker for auto-farming goals in the Phasmophobia lobby. It runs on optimally fast settings (simulating real keyboard inputs), so the game does not block it.

## 🛠 Installation Guide

### Step 1. Download Python
You must have Python installed, preferably version 3.13. 
1. Download Python from the official website.
2. **IMPORTANT:** During installation, make sure to check the **"Add python.exe to PATH"** box in the very first window of the installer.

### Step 2. Install Libraries (One-time setup)
Open your terminal (command prompt) in the folder containing the script and run the following command:

```bash
pip install keyboard pydirectinput
```

*Press Enter and wait for the installation to complete.*

### Step 3. Running and Controls
1. Run the script via your code editor or by using the terminal command:
  
```bash
python main.py
```
  
2. Open Phasmophobia, walk up to the hoop, and aim your crosshair directly at the ball.
3. Controls:
   * **F8** — Start / Stop auto-farming.
   * **ESC** — Close the program completely.

### ⚠️ JUST IN CASE
> **If the keys are not registering in the game:** close the script, run your IDE / Terminal **as administrator**, and start the code again. Games often require admin privileges to intercept and simulate keypresses.
